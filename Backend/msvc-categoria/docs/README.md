# 📚 Documentación del Microservicio Categorías Empresarial

Bienvenido a la documentación completa del microservicio `msvc-categoria` **versión empresarial robusta**. Aquí encontrarás toda la información técnica, guías de configuración y recursos necesarios para entender, desarrollar y desplegar el servicio con **entidad robusta de 65+ campos especializados** y **arquitectura empresarial completa**.

## 🌟 **Características Empresariales Destacadas**

### 🎯 **Entidad Robusta Implementada**
- **65+ campos especializados** organizados en 10 grupos funcionales
- **Sistema de jerarquías multinivel** (hasta 10 niveles de profundidad)
- **5 DTOs especializados** para diferentes casos de uso empresarial
- **SEO integrado** con campos dedicados para optimización web
- **Métricas automáticas** con sistema de popularidad y analíticas
- **Auditoría completa** con seguimiento de cambios y contexto de usuario
- **Soft delete empresarial** con auditoría de eliminación

### 🏗️ **Arquitectura Empresarial**
- **Principios SOLID** aplicados en toda la estructura
- **Clean Architecture** con separación clara de responsabilidades  
- **MapStruct avanzado** para transformaciones complejas entre DTOs
- **Specifications JPA** para filtros dinámicos complejos
- **Spring Boot 3.5.5** con Java 21 LTS para máximo rendimiento
